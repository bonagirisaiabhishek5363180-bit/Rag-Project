THE ARCHITECTURE

01 INGESTION & CHUNKING

Process unstructured text.

Documents are ingested and semantically split into manageable chunks optimized for embeddings.

02 EMBEDDINGS

Map meaning to vectors.

Chunks are passed through an embedding model to create dense vector representations.

03 HYBRID RETRIEVAL

Chroma + BM25

Queries execute a semantic vector search in ChromaDB alongside a lexical BM25 search for exact keywords. The results are merged.

04 RERANKING

CrossEncoder Precision

A specialized CrossEncoder scores the merged candidates against the query, pushing the strongest evidence to the top.

05 GENERATION

Synthesize the answer.

The top context is injected into the LLM prompt. The generator synthesizes a grounded answer.
